# CognioSynthesis Portal UK v2

Enterprise-grade website built with Astro, inspired by DXC Technology industry standards.

## Quick Start

```bash
npm install
npm run dev
```

## Project Structure

```
├── src/
│   ├── pages/          # Route files (.astro, .md)
│   ├── components/     # Reusable UI components
│   ├── layouts/        # Page layout templates
│   └── styles/         # Global and component CSS
├── public/             # Static assets (images, fonts)
└── package.json
```

## Build Stack

- **Framework:** Astro 5.x
- **Style:** CSS custom properties + BEM naming
- **Performance:** Partial hydration, static generation
